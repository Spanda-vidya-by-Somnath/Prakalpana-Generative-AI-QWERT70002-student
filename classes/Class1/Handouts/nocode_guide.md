# The No-code path: your tools

Every session has a No-code path that everyone completes. You need only a browser. These are the tools.

| Tool | What for | Sessions |
|---|---|---|
| **Google AI Studio** (aistudio.google.com) | Prompt playground: system prompt, temperature, structured output, file and image upload, function calling, audio | 1, 4–8, 15–18 |
| **NVIDIA build playground** (build.nvidia.com) | Try many models side by side, including reasoning and vision models | 4, 5, 16 |
| **The course scripts, run-only** (VS Code) | Run the session's script and change only the lines marked `# change me` | all |
| **A spreadsheet** (Google Sheets) | Prompt test sets, A/B scoring, evaluation sheets, cost calculations | 5, 7, 13, 22 |
| **NotebookLM** (notebooklm.google.com) | Ask questions over your own documents: a ready-made RAG to compare with ours | 11, Project 1 |
| **Pinecone console** (app.pinecone.io) | See a vector database: upload, query, filter | 10 |
| **Tokenizer pages** (e.g. platform.openai.com/tokenizer) | See text split into tokens | 5 |
| **A web API in the browser** (any JSON URL; petstore3.swagger.io "Try it out") | See requests, responses and status codes without code | 3 |

## How to work on the No-code path

1. Open the session's script in VS Code and press ▶ Run Python File. Read the output: the comments explain what you see.
2. Change a `# change me` value (a question, a temperature, a document) and run that cell again. Note what changed.
3. Do the playground exercise in the lab handout and record results in a sheet.
4. For homework, write down observations: what you changed, what happened, why you think it happened.

You will be able to explain how every part works. In interviews, that matters more than having typed the code.
