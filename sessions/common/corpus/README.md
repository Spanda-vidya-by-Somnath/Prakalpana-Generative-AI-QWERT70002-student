# Monsoon Mart handbook: the course's shared document set

A fictional online grocery company (Pune and Bengaluru). Used by every RAG-related session (11–13, 15, 18–21).
Sessions copy these files into their own `data/docs/` so each session folder is self-contained.
Facts are deliberately specific (numbers, dates, exceptions) so retrieval can be checked. `returns-2025-archived.md`
contradicts the current returns policy on purpose (stale-document lesson, Session 12). `vendor-note.md` carries a
hidden instruction on purpose (indirect prompt injection, Session 19).
